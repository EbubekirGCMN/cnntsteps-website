3. Ihre Verantwortung für Aufzeichnungen

Wenn Sie Inhalte mit personenbezogenen Daten anderer Personen aufzeichnen, speichern oder weitergeben, sind Sie selbst dafür verantwortlich, dass dies zulässig ist – etwa gegenüber Kundinnen und Kunden, Kolleginnen und Kollegen oder Ihrem Arbeitgeber.

데이터시점처리 방식
기록된 창 또는 선택한 영역의 스크린샷사용자가 직접 시작한 기록 또는 빠른 캡처 중에만사용자가 선택한 위치에 있는 기록 파일(.steps) 및 이를 바탕으로 작성된 문서에 저장됩니다. 기록 중에는 이미지가 사용자 프로필의 작업 폴더에 임시로 저장되며, 앱은 기록이 끝나면 이 폴더를 비우고 충돌이 발생한 경우에는 다음 시작 시 비웁니다.
창 제목, 프로그램 이름 및 클릭한 컨트롤의 이름기록 또는 빠른 캡처 중에만단계를 설명하는 데 사용되며 기록 파일에 저장됩니다. 입력란, 목록 및 표 셀의 경우 그 안에 표시된 내용일 수도 있습니다.
키보드 입력기록 중에만앱은 특정 키를 인식하기 위해 키보드 입력을 감지합니다. Ctrl, Alt 또는 Windows 키를 사용한 키 조합(예: Ctrl+S)과 Delete 키는 키 이름으로 단계에 저장되며, 문자와 텍스트 입력은 폐기되고 저장되지 않습니다.
바로 가기 키앱이 실행되는 동안(그렇게 설정한 경우 알림 영역에서 실행되는 동안에도)앱은 빠른 캡처용 Print Screen 키 등 개별 키 조합을 Windows에 등록합니다. Windows는 정확히 이 조합이 눌린 시점만 앱에 알려 주며, 앱은 이 과정에서 다른 키보드 입력을 받지 않습니다.
암호 입력란클릭할 때클릭한 암호 입력란은 Windows가 이를 암호 입력란으로 보고하는 범위에서 이미지에서 알아볼 수 없게 처리되며, 그 내용은 텍스트로 가져오지 않습니다. 이는 추가적인 보호 조치일 뿐 보장은 아닙니다.
마이크받아쓰기를 켠 경우에만음성은 사용자의 기기에서 텍스트로 변환됩니다. 이 과정에서 오디오 데이터는 저장되지 않습니다.
작성자 이름문서를 작성할 때설정에서 이름을 입력하지 않으면 앱은 사용자의 Windows 사용자 이름을 사용합니다. 이 이름은 작성된 문서에 표시됩니다.
이미지의 텍스트 인식사용자가 켠 경우에만 사용됨. 내역에서 처음 검색할 때 앱이 한 번 물어보며, ‘텍스트 인식 및 가리기’에서 변경할 수 있음Windows가 사용자의 기기에서 스크린샷의 텍스트를 인식합니다. 이는 내역 검색과 “민감한 데이터 찾기”에 사용됩니다. 인식된 텍스트는 기록의 설명, 메모 및 창 제목과 함께 사용자 프로필의 검색 인덱스에 보관됩니다.
내 데이터(픽셀화용)“민감한 데이터 찾기”를 사용할 때앱이 항상 찾아서 픽셀화해야 하는 정보로, 사용자의 Windows 이름이 미리 입력되어 있으며 변경하거나 끌 수 있습니다. 이 정보는 사용자 프로필의 설정에 저장됩니다.

3. 기록에 대한 사용자의 책임

스크린샷에는 기록된 창에 보이는 모든 것이 담깁니다. 여기에는 이름, 이메일 주소, 고객 데이터와 같은 개인정보도 포함됩니다. “민감한 데이터 찾기” 기능이 이러한 내용을 찾는 데 도움이 될 수 있지만(Windows 텍스트 인식 사용, 사용자의 기기에서 실행), 모든 것을 찾아내지는 못합니다. 기록을 공유하기 전에 사용자가 직접 확인하십시오. 편집기에서 이미지를 자르거나 일부를 가리거나 흐리게 처리할 수 있습니다.

다른 사람의 개인정보가 포함된 내용을 기록, 저장 또는 공유하는 경우, 이것이 허용되는지 확인할 책임은 사용자 본인에게 있습니다. 예를 들어 고객, 동료 또는 고용주와의 관계에서 그러합니다.

구매: 당사는 사용자에 대해 스스로 판매자가 되는 리셀러(“Merchant of Record”)를 통해 라이선스를 판매합니다. 현재는 FastSpring(Bright Market, LLC, 미국)이 예정되어 있습니다. 리셀러는 자체 개인정보 처리방침에 따라 이름, 이메일 주소, 우편 주소 및 결제 데이터를 독자적으로 수집하며, 라이선스 키가 포함된 구매 확인서도 사용자에게 보냅니다. 당사는 라이선스를 관리하고 문의에 답변하기 위해 리셀러로부터 주문 데이터(이름, 이메일 주소, 국가 및 주문 번호)를 받습니다(GDPR 제6조 제1항 (b)호). 당사는 결제 데이터를 받지 않습니다.

  • 라이선스 키의 체크섬(키 자체가 아님) 및 컴퓨터 식별자의 체크섬

웹사이트 cnntsteps.com은 Cloudflare Pages(Cloudflare, Inc., 미국)를 통해 제공됩니다. 앱 다운로드와 라이선스 서비스도 Cloudflare를 통해 이루어집니다. 방문 시 해당 제공업체는 사이트를 제공하고 공격으로부터 보호하기 위해 사용자의 IP 주소, 시간, 요청한 주소, 브라우저 등 기술적으로 필요한 데이터를 처리합니다(GDPR 제6조 제1항 (f)호). 이 웹사이트는 쿠키를 설정하지 않고, 사용자의 브라우저에 아무것도 저장하지 않으며, 분석 또는 추적 도구나 제3자의 글꼴 또는 콘텐츠를 사용하지 않습니다. Microsoft Store 또는 당사 리셀러로 연결되는 링크는 해당 사이트로 이동하며, 그곳에서는 해당 사이트의 개인정보 보호 고지가 적용됩니다.

사용자의 기록과 문서는 사용자가 저장한 위치에 있는 일반 파일이며, 언제든지 삭제할 수 있습니다. Microsoft Store 버전을 제거하면 Windows가 앱의 설정, 로그 및 기타 데이터를 삭제합니다. 당사 웹사이트 버전의 경우 제거 시 로그, 검색 인덱스, 임시 이미지 및 문제 보고서가 삭제되며, 설정과 복구 파일(저장되지 않은 기록)은 다시 설치했을 때 이어서 사용할 수 있도록 남아 있습니다. 업데이트 시에는 아무것도 삭제되지 않습니다. 당사 웹사이트 버전이 Microsoft Store 버전보다 먼저 설치되어 있었다면, 그 데이터는 Microsoft Store 버전을 제거한 후에도 남아 있습니다. 빠른 캡처의 임시 파일은 3일 후 앱이 삭제합니다. Microsoft Store 버전은 다운로드한 받아쓰기 모델 “Whisper”를 자체 데이터 폴더에 저장하며, 이 폴더는 앱을 제거할 때 Windows가 함께 삭제합니다. 당사 웹사이트 버전의 받아쓰기 모델, 이전 모델(폴더 %USERPROFILE%\.cache\huggingface) 및 사용자가 Windows 사전에 추가한 단어는 앱을 제거할 때 함께 삭제되지 않으며, 둘 다 사용자가 직접 삭제할 수 있습니다. 설정의 ‘텍스트 인식 및 가리기’ 섹션에 있는 “로컬 데이터 삭제”를 사용하면 로그, 문제 보고서, 빠른 캡처의 임시 파일 및 이미지에서 인식된 텍스트를 언제든지 직접 삭제할 수 있습니다.
